# TDTU Coursework & Projects

Academic repository containing coursework, reports, laboratory assignments, presentation slides, and source code for Ton Duc Thang University (TDTU).

---

## 📚 Subject Directory Guide

| Folder | Subject / Scope | Key Deliverables & Highlights |
|---|---|---|
| **`BMMT/`** & **`ComputerSec/`** | Information & Computer Security | Lab reports (Snort, Firewall, Server logs), Linux Auth & Authz, Digital Signatures. |
| **`DA/`** | Data Analytics | Midterm analysis, Endterm Theory (`Nor`), Endterm Practice (`Prac`), Regression models. |
| **`ML/`** | Machine Learning | 38-page LaTeX Midterm Report, 16:9 Presentation Deck, Mobile Interactive Deck, OpenML benchmarks. |
| **`SE/`** | Software Engineering | SaigonBite Food Delivery Platform, Part 1 Project Proposal, Spec Kit, Playwright & Unit test suites. |
