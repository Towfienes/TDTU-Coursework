# Dataset attribution and reuse

Hofmann, H. (1994). Statlog (German Credit Data). UCI Machine Learning Repository. DOI: https://doi.org/10.24432/C5NC77.

Origin: https://archive.ics.uci.edu/dataset/144/statlog+german+credit+data
OpenML distribution: https://www.openml.org/d/31, version 1.

The originating UCI page states Creative Commons Attribution 4.0 International (CC BY 4.0): https://creativecommons.org/licenses/by/4.0/. OpenML metadata separately labels its license Public. This package preserves the original OpenML ARFF bytes without modification. Experiments transform features in memory only. Attribution and license notices are retained for reuse.

Checked on 9 October 2026. No identity between the OpenML ARFF and a differently formatted UCI file is asserted.
