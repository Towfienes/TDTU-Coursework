\section{Experimental principles}
A low training loss does not establish generalization. The experiments separate learning from evaluation, record random seeds and fit preprocessing on training records only.

Question 1 uses NumPy for predictions, losses, gradients and updates; library utilities only split and evaluate data. Question 2 reuses scratch logistic regression and uses scikit-learn for the other classifiers.

For Question 2, a stratified 80/20 split reserves 200 records for testing. Model and parameter selection use identical five-fold stratified cross-validation within the remaining 800 records. Macro F1 is the selection metric because both classes should contribute to the comparison. All model choices are completed before any held-out test predictions are produced. The test results are reported for comparison, without retuning the models.

\chapter{QUESTION 1: GRADIENT DESCENT}
\section{Notation and data preparation}
Let the training set be $\{(x_i,y_i)\}_{i=1}^{n}$, where $x_i\in\mathbb R^d$. Rows of $X\in\mathbb R^{n\times d}$ are the feature vectors $x_i^{\symup{T}}$. Both models have feature weights $w\in\mathbb R^d$ and an intercept $b\in\mathbb R$. Let $\mathbf1\in\mathbb R^n$ denote a vector of ones and $\eta>0$ the learning rate.

A train/test split is performed before fitting a transformation. For a numerical feature $j$, min--max scaling uses only the training minimum $m_j$ and range $r_j$:
\[
\tilde x_{ij}=\frac{x_{ij}-m_j}{r_j},\qquad
m_j=\min_{i\in train}x_{ij},\quad
r_j=\max_{i\in train}x_{ij}-m_j.
\]
The code uses a denominator of 1 if a training feature is constant. Test values are transformed with the same training quantities and can lie outside $[0,1]$. They are not clipped or used to recompute the scale. Scaling makes the GD step size easier to manage; it does not change the identity of the observations.

The derivations below use $x_i$ for the features supplied to the model, which are the scaled features in the experiments. The raw-unit coefficients can be recovered as $w_j^{raw}=w_j/r_j$ and $b^{raw}=b-\sum_j w_jm_j/r_j$ when $r_j>0$.

\source{Lecture 3, pp. 18--25; Lecture 8, pp. 6--19.}

\section{Linear regression}
\subsection{Model, prediction and task}
Linear regression predicts a continuous target from an affine combination of features:
\[
\hat y_i=w^{\symup{T}}x_i+b,\qquad \hat y=Xw+b\mathbf1.
\]
For a single feature, this becomes a straight line. For multiple features, it is a hyperplane. Unlike a binary classifier, the prediction is a real number without a probability constraint. Applications in the course include predicting weight or house price. The experiment below uses a synthetic continuous target with a known linear data-generating relation.

\subsection{Loss function}
The mean half-squared-error loss is
\[
J_L(w,b)=\frac{1}{2n}\sum_{i=1}^{n}(w^{\symup{T}}x_i+b-y_i)^2.
\]
The factor $1/2$ simplifies differentiation and does not change the minimizer. The division by $n$ makes the loss an average. The evaluation metric MSE is $2J_L$ on the same observations, not $J_L$. Squaring makes large residuals contribute strongly, so extreme target errors can have a substantial effect on the fitted model.

\subsection{Derivation of the gradients}
Define $e_i=w^{\symup{T}}x_i+b-y_i$. For any feature weight $w_j$,
\[
\frac{\partial e_i}{\partial w_j}=x_{ij},\qquad
\frac{\partial e_i}{\partial b}=1.
\]
Applying the chain rule to each squared residual gives
\[
\begin{aligned}
\frac{\partial J_L}{\partial w_j}
 &=\frac{1}{2n}\sum_{i=1}^{n}2e_i\frac{\partial e_i}{\partial w_j}
 =\frac1n\sum_{i=1}^{n}e_ix_{ij},\\
\frac{\partial J_L}{\partial b}
 &=\frac{1}{2n}\sum_{i=1}^{n}2e_i
 =\frac1n\sum_{i=1}^{n}e_i.
\end{aligned}
\]
Writing $e=Xw+b\mathbf1-y$, the same gradients are
\[
\nabla_wJ_L=\frac1nX^{\symup{T}}e,\qquad
\frac{\partial J_L}{\partial b}=\frac1n\mathbf1^{\symup{T}}e.
\]
The vector gradient has $d$ components and the intercept gradient is a scalar. These dimensions match the parameters that are updated.

\subsection{Training algorithm}
Initialize $w^{(0)}=0$ and $b^{(0)}=0$. At iteration $t$, predict using the current parameters and calculate the residuals
\[
e^{(t)}=Xw^{(t)}+b^{(t)}\mathbf1-y.
\]
Then perform the simultaneous updates
\[
\begin{aligned}
w^{(t+1)}&=w^{(t)}-\eta\frac1nX^{\symup{T}}e^{(t)},\\
b^{(t+1)}&=b^{(t)}-\eta\frac1n\mathbf1^{\symup{T}}e^{(t)}.
\end{aligned}
\]
Both gradients are computed before either parameter is changed. Full-batch GD uses every training example at each iteration. A learning rate that is too large can cause divergence; one that is too small can make learning slow. The stopping rule uses the training gradient norm or a maximum iteration budget, never the test metrics.

\source{Lecture 8, pp. 6--20 and 24.}

\section{Logistic regression}
\subsection{Model, prediction and task}
Logistic regression is a binary classification model for labels $y_i\in\{0,1\}$. It maps an affine score to a probability:
\[
z_i=w^{\symup{T}}x_i+b,\qquad
p_i=P(y_i=1\mid x_i)=\sigma(z_i)=\frac1{1+e^{-z_i}}.
\]
Consequently $P(y_i=0\mid x_i)=1-p_i$. The probability is bounded between 0 and 1 for finite scores, whereas the score itself is unrestricted. Its log-odds are affine:
\[
\log\frac{p_i}{1-p_i}=w^{\symup{T}}x_i+b.
\]
The experiment uses a fixed decision rule $\hat y_i=1$ if $p_i\ge0.5$, and $\hat y_i=0$ otherwise. This corresponds to a boundary at $z_i=0$. Probabilities, rather than thresholded labels, are used for ROC-AUC.

\subsection{Appropriate loss and likelihood}
For independent training observations, the Bernoulli likelihood is
\[
\mathcal L(w,b)=\prod_{i=1}^{n}p_i^{y_i}(1-p_i)^{1-y_i}.
\]
Maximizing this likelihood is equivalent to minimizing its negative mean log-likelihood, the binary cross-entropy loss:
\[
J_G(w,b)=-\frac1n\sum_{i=1}^{n}\left[y_i\log p_i+(1-y_i)\log(1-p_i)\right].
\]
Natural logarithms are used. A confident wrong prediction incurs a large loss. Squared error is therefore not substituted for the cross entropy taught for logistic regression.

\subsection{Derivation of the gradients}
First differentiate the sigmoid:
\[
\begin{aligned}
\sigma'(z)&=\frac{e^{-z}}{(1+e^{-z})^2}\\
 &=\frac1{1+e^{-z}}\left(1-\frac1{1+e^{-z}}\right)
 =\sigma(z)(1-\sigma(z)).
\end{aligned}
\]
For one observation, let $\ell_i=-y_i\log p_i-(1-y_i)\log(1-p_i)$. Its derivative with respect to the probability is
\[
\frac{\partial\ell_i}{\partial p_i}
 =-\frac{y_i}{p_i}+\frac{1-y_i}{1-p_i}.
\]
Applying the chain rule through $p_i=\sigma(z_i)$ simplifies the derivative with respect to the score:
\[
\begin{aligned}
\frac{\partial\ell_i}{\partial z_i}
 &=\left(-\frac{y_i}{p_i}+\frac{1-y_i}{1-p_i}\right)p_i(1-p_i)\\
 &=-y_i(1-p_i)+(1-y_i)p_i=p_i-y_i.
\end{aligned}
\]
Finally, $\partial z_i/\partial w_j=x_{ij}$ and $\partial z_i/\partial b=1$, hence
\[
\begin{aligned}
\frac{\partial J_G}{\partial w_j}&=\frac1n\sum_{i=1}^{n}(p_i-y_i)x_{ij},\\
\frac{\partial J_G}{\partial b}&=\frac1n\sum_{i=1}^{n}(p_i-y_i).
\end{aligned}
\]
In matrix form, with $p=\sigma(Xw+b\mathbf1)$ applied elementwise,
\[
\nabla_wJ_G=\frac1nX^{\symup{T}}(p-y),\qquad
\frac{\partial J_G}{\partial b}=\frac1n\mathbf1^{\symup{T}}(p-y).
\]
The result resembles the linear-regression gradient, but the prediction function and loss differ.

\subsection{Training and stable computation}
Initialize both parameters at zero. At each iteration, compute $z$, $p$, $J_G$ and both gradients using the current parameters, then update
\[
\begin{aligned}
w^{(t+1)}&=w^{(t)}-\eta\frac1nX^{\symup{T}}(p^{(t)}-y),\\
b^{(t+1)}&=b^{(t)}-\eta\frac1n\mathbf1^{\symup{T}}(p^{(t)}-y).
\end{aligned}
\]
The code evaluates the sigmoid as $1/(1+e^{-z})$ for $z\ge0$ and $e^z/(1+e^z)$ for $z<0$. The two expressions are equal, but this form avoids exponentiating a large positive number. Substituting the sigmoid into the cross entropy also gives
\[
\ell_i=\log(1+e^{z_i})-y_iz_i.
\]
NumPy's logaddexp operation evaluates the logarithmic term stably. These are numerical implementations of the same model and objective, not a change of loss.

The mean-loss gradient includes $1/n$. This follows Lecture 9, p. 42, and keeps the update consistent with the defined objective even though the summary update on p. 43 omits that factor.

\source{Lecture 9, pp. 16--21 and 29--43.}

\section{Python implementation and verification}
The accompanying file \texttt{src/models.py} contains the complete implementations. The linear loss function computes the residual vector, mean half-squared loss, matrix gradient and mean intercept gradient. The logistic loss function computes the stable logits-based cross entropy and the corresponding probability residual.

The two classes share a GD loop because only the prediction residual and loss change. The loop follows this procedure:
\begin{enumerate}
\item Validate finite two-dimensional features and a one-dimensional target; require 0/1 labels for logistic regression.
\item Initialize weights and intercept at zero. Store the loss before any update.
\item Compute the current training loss and both gradients. Reject non-finite values as a divergence error.
\item Stop if the full gradient norm is at most $10^{-8}$ or the iteration budget has been reached.
\item Otherwise update all parameters from those gradients and repeat. Record the resulting loss at the next iteration.
\end{enumerate}
The history therefore includes iteration 0 and the final parameter state. Prediction checks that the feature dimension agrees with the fitted model. The scikit-learn adapter used in Question 2 delegates optimization to the same NumPy logistic implementation.

To verify the gradients independently, the tests compare each analytic derivative with a central finite difference of the loss:
\[
g_j^{FD}=\frac{J(\theta+h e_j)-J(\theta-h e_j)}{2h},\qquad h=10^{-6},
\]
where $\theta=(w_1,\ldots,w_d,b)$ and $e_j$ is a coordinate unit vector. Both losses pass the comparison with relative tolerance $10^{-6}$ and absolute tolerance $10^{-8}$. Additional tests fit an exact linear relation, classify separable examples, check probabilities sum to one, exercise logits of $\pm1000$, and reject invalid inputs. No finite-difference gradient is used for training.

\section{Linear regression experiment}
\subsection{Dataset and training setup}
The synthetic dataset has 600 examples with three independent features drawn uniformly from $[-3,3]$, using NumPy seed 42. Its target is
\[
y=4+3x_1-2x_2+1.5x_3+\varepsilon,\qquad
\varepsilon\sim\mathcal N(0,0.5^2).
\]
A shuffled 80/20 split with seed 42 produces 480 training and 120 test examples. The training features determine the min--max scale. GD starts from zero, uses $\eta=0.3$, and has a maximum of 4,000 updates. It stops after \LinIterations{} updates because the training gradient norm falls below $10^{-8}$.

\subsection{Metrics and results}
Let $m$ denote the number of test examples. The regression metrics are
\[
\begin{aligned}
\mathrm{MSE}&=\frac1m\sum_i(y_i-\hat y_i)^2,&
\mathrm{RMSE}&=\sqrt{\mathrm{MSE}},\\
\mathrm{MAE}&=\frac1m\sum_i|y_i-\hat y_i|,&
R^2&=1-\frac{\sum_i(y_i-\hat y_i)^2}{\sum_i(y_i-\bar y_{test})^2}.
\end{aligned}
\]
MSE has squared target units; RMSE and MAE have target units. The $R^2$ denominator uses the mean of the evaluated test targets, as in the lecture metric definition. It is an evaluation calculation, not a parameter fitted on the test set.

\section{Logistic regression experiment}
\subsection{Dataset and training setup}
A separate random generator with seed 43 creates 800 examples with two independent standard-normal features. First define
\[
p^{true}(x)=\sigma(0.8+1.6x_1-1.2x_2),
\]
then draw a Bernoulli label by comparing an independent uniform random number with this probability. Thus labels are probabilistic rather than perfectly separated by a line. This prevents a visually simple boundary from implying that every label must be predicted correctly.

A stratified 80/20 split with seed 42 gives 640 training and 160 test examples. The positive class has 393 training and 98 test examples. GD uses the training min--max scale, $\eta=0.5$ and a maximum of 5,000 updates. The iteration budget is reached; the final gradient norm is about $1.55\times10^{-4}$, so the strict $10^{-8}$ stopping tolerance is not reached. Neither the budget nor threshold is chosen using the test results.

\subsection{Metrics and results}
For positive class 1, let TP, FP, FN and TN be the confusion counts. We use
\[
\begin{aligned}
\mathrm{Accuracy}&=\frac{TP+TN}{m},&
\mathrm{Precision}&=\frac{TP}{TP+FP},\\
\mathrm{Recall}&=\frac{TP}{TP+FN},&
F_1&=\frac{2TP}{2TP+FP+FN}.
\end{aligned}
\]
Macro F1 averages the two class-specific F1 values. ROC-AUC evaluates the ordering induced by the predicted probabilities across thresholds. Undefined precision or F1 is assigned zero in the evaluation code.

\chapter{QUESTION 2: CLASSIFICATION}
\section{Dataset and prediction task}
The dataset is \textit{credit-g}, OpenML ID 31, version 1, also described as German Credit. Its official ARFF contains 1,000 records, 20 predictors and a class target with labels \texttt{good} and \texttt{bad}. The OpenML metadata credits Dr. Hans Hofmann and lists a public licence. The experiment preserves the downloaded ARFF and metadata alongside the code.

The target is mapped to $0=good$ and $1=bad$. There are 700 good and 300 bad records. The task is to predict this supplied classification label from the predictors; the experiment is an academic classification comparison on this historical dataset.

The seven numerical predictors are duration, credit amount, installment commitment, residence since, age, existing credits and number of dependents. The remaining 13 predictors are categorical: checking status, credit history, purpose, savings status, employment, personal status, other parties, property magnitude, other payment plans, housing, job, own telephone and foreign worker. No row identifier is used as a predictor.

\noindent Source: \url{https://www.openml.org/d/31}. The official data checksum is verified before loading. Its MD5 is \texttt{9a475053fed0c26ee95cd4525e50074c}; the complete SHA-256 is preserved in \texttt{results/q2\_audit.json}.

\section{Data audit, cleaning and visualization}
The loader decodes ARFF categorical values, recognizes the missing marker, checks the exact expected shape and target vocabulary, and audits missing cells, duplicate records and non-finite numeric values. The observed audit finds zero missing cells, zero duplicated rows and zero non-finite numeric values. Thus no record is deleted or imputed. Reporting this clean audit is more accurate than claiming that a cleaning operation removed records when none needed removal.

The train/test split is created before exploratory plots or learned transformations. All exploratory plots use the 800 development records, consisting of 560 good and 240 bad examples. The 200 held-out records contain 140 good and 60 bad examples. During five-fold CV, each fold trains on 640 records and validates on 160; class proportions are preserved.

\plot{q2_eda.png}{Development-set class balance, numeric distributions and checking status.}{fig:eda}
The class distribution is imbalanced. A classifier that always predicts good obtains 70\% accuracy while detecting no bad examples. This makes accuracy alone an inadequate comparison criterion.

Credit amount is right-skewed: its development median is 2,317 and maximum is 15,945 in the original units. Age ranges from 19 to 75 years and the two class distributions overlap. Checking status shows different within-category class proportions. These plots motivate scaling, categorical encoding and multi-feature classification; they do not establish a causal relationship.

A development-only interquartile-range audit flags 58 credit-amount values and 25 ages outside the corresponding $[Q_1-1.5\,IQR,Q_3+1.5\,IQR]$ intervals. These are descriptive extreme-value flags, not verified data errors, so they are retained. The number-of-dependents feature is particularly instructive: its first and third quartiles are both 1, so this rule flags all 128 records with value 2. Deleting them merely because of this zero-IQR rule would remove legitimate categories. The complete numeric audit is saved for inspection.

\section{Transformation, scaling and leakage control}
Numerical features are min--max scaled using the minimum and maximum of each training fold. All categorical predictors are one-hot encoded, without imposing an artificial ordering on their values. All observed categories are retained; unknown categories at prediction time map to zero in the corresponding block. The transformation refitted on all 800 development records produces 61 numerical and indicator features in total.

The preprocessing transformer is placed inside the classification pipeline, so every CV fit learns its own ranges and category vocabulary from the fold's training subset. Validation and test data only pass through the fitted transformation. The target is separated first and is never encoded as an input feature. An independent test verifies that an extreme unseen age can transform to a value above 1 without changing the training maximum, and that an unseen category does not enter the fitted vocabulary.

The same numerical scaling and categorical encoding are used for all comparative models. This is essential for distance-based and margin-based methods; it is harmless for the threshold splits of tree models. Gaussian Naive Bayes models continuous densities on the resulting features, including indicators, so its Gaussian assumption is only approximate for binary columns. Bernoulli Naive Bayes instead keeps the indicators binary and converts each scaled numerical feature to $\mathbf1[\tilde x_j>0.5]$. This is a declared transformation that loses numeric detail, rather than an unreported change to the common dataset.

No oversampling, test-informed threshold selection, pretrained representation or additional feature source is used. In particular, the class imbalance is addressed through the evaluation criterion and class-specific reporting rather than through an unrequested resampling method.

\source{Lecture 3, pp. 18--25; Lecture 4, pp. 37--42.}

\section{Classification methods}
Fourteen learned classifier entries are compared. The three SVM kernels are variants of one family; they are not counted as independent algorithm families. The following descriptions identify the model mechanisms taught in the slides.

\subsection{Linear classifiers and nearest neighbors}
\textbf{Scratch logistic regression} uses the probability model and full-batch GD derived in Chapter 2. Its optimization is reused rather than replaced by a library logistic estimator. The 0.5 threshold remains fixed.

\textbf{Perceptron} forms $z=w^{\symup{T}}x+b$ and a hard classification boundary. With labels $s_i\in\{-1,+1\}$, the lecture update on a misclassified example is $w\leftarrow w+\eta s_ix_i$, with an analogous intercept update. The library performs the corresponding label handling. A finite number of passes is used because real labels need not be linearly separable.

\textbf{kNN} predicts by a majority vote among the $k$ nearest training records under Euclidean distance. Numerical scaling prevents credit amount from dominating purely through its units. Uniform voting is used; candidate values of $k$ explore the trade-off between local sensitivity and a smoother decision rule.

\source{Lecture 3, pp. 4--25; Lecture 9, pp. 4--14 and 29--43.}

\subsection{Naive Bayes and decision trees}
\textbf{Naive Bayes} chooses the class maximizing $P(c)\prod_jP(x_j\mid c)$, under conditional independence of features given the class. Gaussian NB estimates a mean and variance for each feature within each class. Bernoulli NB estimates probabilities for the binary transformed features and uses additive smoothing. One-hot indicators from the same original predictor are dependent, so the independence assumption is a limitation of both comparisons.

\textbf{Decision tree} predicts by following feature tests from the root to a leaf. For a node with class proportions $p_c$, candidate split criteria include
\[
H=-\sum_c p_c\log_2p_c,\qquad G=1-\sum_c p_c^2.
\]
The compared library tree uses binary threshold splits with entropy or Gini impurity. It is not presented as an exact implementation of categorical, multiway ID3. Maximum depth and minimum leaf size constrain its complexity.

\source{Lecture 4, pp. 13--31 and 37--42; Lecture 5, pp. 18--34.}

\subsection{Support vector machines and neural network}
\textbf{SVM} seeks a separating margin while allowing errors through the soft-margin parameter $C$. Kernel comparisons use the linear dot product, radial basis function and polynomial kernels:
\[
\begin{aligned}
K_L(x,z)&=x^{\symup{T}}z,\\
K_R(x,z)&=\exp(-\gamma\|x-z\|^2),\\
K_P(x,z)&=(\gamma x^{\symup{T}}z+r)^q.
\end{aligned}
\]
The polynomial experiment fixes $r=0$ and compares degrees 2 and 3. The SVM decision score is used for ROC-AUC; it is not called a calibrated probability.

\textbf{MLP} is a feedforward neural network with one hidden layer and a nonlinear activation. Here it uses 16 or 32 tanh hidden units and a binary output. Backpropagation applies the chain rule to compute gradients; stochastic gradient descent updates the weights. This differs from the full-batch GD explicitly required and implemented in Question 1. The library uses a binary cross-entropy objective, so the quadratic-loss output derivative shown in Lecture 10 is not copied unchanged.

To keep optimization choices explicit, the MLP uses no weight penalty, no momentum and no early stopping. It trains for a fixed 500 epochs, with batch size at most 200. The result logs retain the maximum-iteration warnings. The report therefore does not claim that the MLP reaches a converged optimum.

\source{Lecture 7, pp. 3--34; Lecture 10, pp. 3--32; Lecture 9, pp. 29--43.}

\subsection{Ensemble classifiers and scope of comparison}
\textbf{Bagging} trains decision trees on bootstrap samples and aggregates their outputs. It reduces dependence on a single fitted tree. \textbf{Random forest} adds random feature selection at splits. The forest uses the square root of the encoded feature count as its feature-subset rule.

\textbf{AdaBoost} trains decision stumps sequentially, increases emphasis on misclassified observations and combines weighted weak classifiers. \textbf{Gradient boosting} builds an additive model by fitting successive trees to loss-derived residual information. The number of stages, learning rate and tree depth control the resulting complexity.

A \textbf{majority baseline} always predicts good and is included to show what can be obtained without learning feature--label relationships. It is an evaluation reference, not an additional lecture model.

CNN, RNN, LSTM and Transformer representations appear in the supplied deep-learning slides, but credit-g is a small tabular dataset without a supplied image, sequence or text representation. Imposing those structures would introduce an arbitrary representation and obscure the requested tabular comparison. Clustering is unsupervised and is not treated as a supervised classifier here. Multinomial NB is also omitted because these predictors are not the word-count data used to motivate it in the lectures.

\source{Lecture 13, pp. 2--23; Lecture 11--12, pp. 16--134; Lecture 6, pp. 3--11.}

\section{Validation protocol and parameter selection}
The comparison uses \texttt{StratifiedKFold} with five folds, shuffling and seed 42. All candidate pipelines receive the same fold indices. Parameters are selected by the mean validation macro F1,
\[
F_M=\frac{F_{1,good}+F_{1,bad}}2.
\]
For each configuration, training F1 and validation F1 are recorded on each fold. The sample standard deviation of the five validation scores is also reported. The training--validation gap is the difference between their means.

The finite search covers the following settings; the full per-candidate, per-fold results are included with the code:
\begin{itemize}
\item Scratch logistic: 1,500 or 4,000 GD updates at step 0.5. Perceptron: step 0.01, 0.1 or 1, with 300 passes.
\item kNN: $k\in\{1,5,11,21,41\}$. Gaussian NB: variance smoothing $10^{-9}$, $10^{-5}$ or $10^{-2}$; this library safeguard adds a small variance term. Bernoulli NB: additive smoothing 0.5, 1 or 2.
\item Tree: Gini or entropy, maximum depth 3, 6 or unlimited, and minimum leaf size 1 or 5.
\item SVMs: $C\in\{0.1,1,10\}$; RBF compares scaled $\gamma$ and 0.1; polynomial compares degree 2 and 3.
\item MLP: hidden width 16 or 32, SGD learning rate 0.01 or 0.05, with the common 500-epoch budget.
\item Bagging: depth 4 or unlimited and leaf size 1 or 5, with 50 trees. Random forest: depth 6, 10 or unlimited and leaf size 1 or 5, with 150 trees.
\item AdaBoost: 50 or 150 stumps, step 0.1 or 1. Gradient boosting: 50 or 150 stages, step 0.05 or 0.1, depth 1 or 3.
\end{itemize}

In the tables, $F_M$ denotes macro F1, SD is the sample standard deviation across folds, and all scores lie on the 0--1 scale.

\chapter{OVERFITTING AND REMEDIES}
\section{Definition and experimental evidence}
Overfitting occurs when a model fits the particular training sample too closely and performs substantially worse on unseen examples. Training performance can improve with greater complexity even when validation performance stops improving or declines. Conversely, a model with poor training and validation performance can be underfitting. The training--validation gap is useful evidence, but not a standalone proof that every error is due to overfitting.

Table~\ref{tab:overfit} compares base and CV-selected configurations on the same folds. ``Base'' means the explicitly defined starting estimator in the experiment code; it does not mean that every parameter is the library's default. All four columns are mean macro F1, not accuracy.
\input{q2_overfit_table.tex}
The unrestricted base tree reaches training macro F1 of 1.000 but validation macro F1 of 0.614. The selected depth-6, minimum-leaf-5 tree has training macro F1 of 0.777 and validation macro F1 of 0.656. Its gap decreases from about 0.386 to 0.121. This is a direct experiment showing that limiting tree complexity can reduce overfitting and improve validation performance.

Bagging's gap falls from about 0.328 to 0.221 when a minimum leaf size of 5 is selected. Gradient boosting's selected setting lowers the gap from about 0.270 to 0.217. Random forest still has a large selected gap of about 0.324: ensembling does not guarantee that a model ceases to overfit.

At unlimited depth, training rises to 1.000 while validation falls to 0.614. The curve provides the expected pattern of increased capacity fitting training-specific structure.

This diagnostic differs from the full parameter search, which also varies leaf size and split criterion. It is therefore not expected to reproduce the selected tree's score exactly. A smaller depth or larger leaf size is useful only if it gives a suitable validation trade-off; extreme simplification can underfit.

\section{Model-specific remedies and remaining risks}
\textbf{Linear and logistic regression.} Use a suitable feature set, inspect erroneous extreme values and validate the iteration budget rather than assuming that a lower training loss implies a better classifier. In Question 2, the unpenalized scratch logistic model has a moderate gap of 0.065, with 1,500 updates selected. The experiment does not introduce a penalty absent from the required Question 1 objective. Synthetic Question 1 fits should not be generalized to real-world data.

\textbf{Perceptron.} Inspect whether a linear boundary is adequate and keep a finite training budget on nonseparable data. Its small gap of 0.034 accompanies a relatively low validation mean of 0.590; this is not evidence of a well-fitting model. Improving representation or reconsidering the linear model is more appropriate than treating all low scores as overfitting.

\textbf{kNN.} Increase $k$ to reduce sensitivity to individual records and evaluate the resulting validation score. However, this dataset's search selects $k=1$, whose training score is 1.000 and gap is 0.373. The larger-$k$ candidates are recorded, and the reported selection is not overwritten solely to obtain a smaller gap. A smoother neighbor rule is an available remedy, not a demonstrated improvement in the chosen criterion here.

\textbf{Gaussian and Bernoulli NB.} Their gaps are about 0.046 and 0.022. Check the distribution assumptions and encoding rather than assuming that complex fitting is the main problem. Bernoulli smoothing avoids zero probabilities; numerical binarization loses information. One-hot blocks violate conditional independence, while Gaussian indicators violate the continuous Gaussian shape. These limitations can explain errors even without a large gap.

\textbf{Decision tree.} Limit depth, require more records per leaf, or prune using validation information, as discussed in the slides. The depth and leaf-size search gives the clearest measured reduction in overfitting. Its held-out performance remains weaker, so the mitigation is not described as solving every error.

\textbf{SVM.} A smaller $C$ permits more training violations and can favor a less sample-specific boundary. Kernel choice, polynomial degree and RBF $\gamma$ control flexibility and should be chosen using validation. The selected linear SVM gap is 0.075, compared with 0.321 for RBF and 0.225 for polynomial SVM. The selected nonlinear variants retain a risk of fitting details of the training sample even though their validation means are higher.

\textbf{MLP.} Use a smaller hidden layer and select training duration using validation rather than test performance. The search chooses 16 hidden units instead of 32 and a step size of 0.05. Its gap is approximately 0.064. The base network has both low training and validation scores; increasing the learning rate improves fitting substantially. The fixed 500-epoch run produces maximum-iteration warnings, so insufficient optimization and overfitting must be distinguished. A future validation-based duration comparison would require a fresh evaluation protocol, not retrospective test tuning.

\textbf{Bagging and random forest.} Bootstrap aggregation and random feature subsets reduce reliance on a single tree, while maximum depth and minimum leaf size further constrain each base learner. Their selected gaps remain 0.221 and 0.324. Diversity and averaging help, but strong trees can still memorize the finite development sample.

\textbf{AdaBoost and gradient boosting.} Validate the number of stages, learning rate and weak-learner complexity. Deep trees or too many corrective stages can fit sample-specific errors. AdaBoost here uses decision stumps and has a gap of 0.072; gradient boosting uses depth-3 trees and has a gap of 0.217. Reducing step size or tree complexity can be considered within a training-only search; it is not guaranteed to increase validation performance.

Across all models, the common safeguards are an untouched test set, preprocessing fitted within folds, a declared selection criterion and transparent reporting of training and validation performance. These safeguards improve the credibility of evaluation, but do not themselves make a model more accurate. The observed remedies are distinguished from possible next steps so that no unrun improvement is presented as an experimental result.

\section{Findings and limits}
For Question 1, linear regression learns the known synthetic relation with test $R^2=\LinRSquared$ and RMSE $\LinRMSE$. Logistic regression reaches test accuracy \LogAccuracy\%, positive-class F1 \LogFOne{} and AUC \LogAUC{}. Their analytic gradients agree with finite differences, and both training curves decrease under the specified learning rates.

For Question 2, MLP is selected using the highest mean development macro F1, then evaluated without further tuning. Its test accuracy is 0.790 and macro F1 is 0.7305, but it detects only 32 of 60 bad examples. Scratch logistic provides nearly the same test macro F1 with a simpler affine model. The small differences and fold variability do not support a claim of universal or statistically established superiority.

The decision-tree experiment shows overfitting directly: unlimited depth obtains a perfect training score with a lower validation score than a constrained tree. Other methods show different combinations of capacity, optimization difficulty and distribution assumptions. The report therefore treats overfitting as an observed generalization issue rather than an explanation for every poor result.

The main limits are one historical dataset, one fixed held-out split, modest parameter grids and finite GD/MLP training budgets. The CV means are used for selection and can be optimistic after searching. No independent replication dataset, nested validation or significance claim is added. The report fulfills the requested model derivations, implementations, preprocessing, comparisons and overfitting analysis within the supplied course scope.
