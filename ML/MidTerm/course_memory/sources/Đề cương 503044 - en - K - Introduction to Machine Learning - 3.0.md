Course Objectives (COs)

1

Learners understand, remember and easily express the basic concepts, models and algorithms of machine learning.

2

Learners understand machine learning models, model parameters, model's application, understand algorithms for learning models.

3

Learners can analyze problems and implement Python programming language and machine learning libraries on Python to solve problems using machine learning.

4

Learners have the ability to evaluate machine learning models and analyze problems to choose the most suitable and optimal solution for each problem.

5

Learners are equipped with a scientific basis to be able to self-learn new knowledge in machine learning, and to be creative in solving real-world problems using machine learning.

Brief course content: 

Topics in the module include: conceptual learning, decision trees, neural networks, hypothesis testing, Bayesian learning, case-based learning, genetic algorithms, support vector machines. Skills of applying techniques to solve real problems.

Student’s tasks: 

Attendance:+ Students attend all the class sessions (theory, practice, discussion). Students who are late or absent more than a specified number of days (notice will be given depending on the semester) will not allowed to take the final exam.+ Students build the learning plan of the subject, learn with the spirit of initiative, eager to learn, serious attitude.+ Students learn, improve the knowledge of the subject with relevant documents at the library of Ton Duc Thang University.

Full participation in class activities:+ Students need to be active, cooperative, actively discuss in teamwork.+ Students need to be active, self-discipline, answer questions or argue in the direction of the lesson constructing.

Complete homework assignments:+ Students should read in advance and review the materials after each lesson, while actively reading and expanding the reference materials to complete and improve the knowledge of the course.+ Students have to complete the assigned assignments fully and on time.
